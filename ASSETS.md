# Game assets

Soldank plays with OpenSoldat's base game content, which release archives include unchanged:

* `soldat.smod`: the game's graphics, sounds, maps, animations and configs
* `play-regular.ttf`: the interface font

They come from [opensoldat/base](https://github.com/opensoldat/base), release
[v0.4](https://github.com/opensoldat/base/releases/tag/v0.4): Soldat's content by Michał Marcinkowski
(Transhuman Design) and the OpenSoldat contributors (see the repository's
[Credits.md](https://github.com/opensoldat/base/blob/master/Credits.md)), licensed under
[Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

Soldank's own code is under the MIT licence (`LICENSE`); the CC BY 4.0 licence above covers the files
listed here.
